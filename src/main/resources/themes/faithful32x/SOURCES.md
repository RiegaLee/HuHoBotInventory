## Extracted resources and processing

- GUI source: `assets/minecraft/textures/gui/container/inventory.png`.
- Item sources: selected files under `assets/minecraft/textures/item/`.
- Block-as-item sources: four selected files under `assets/minecraft/textures/block/`.
- Static shield icon: 64x transparent PNG reproducibly pre-baked by
  `tools/ClientEquivalentShieldOverrideGenerator.java` from Faithful's unmodified
  `assets/minecraft/textures/entity/shield/shield_base_nopattern.png`. Plate and handle geometry
  follow Minecraft 26.1.2 `ShieldModel.createLayer()`; the baker applies the shield GUI
  rotation `[15,-25,-5]`, translation `[2,3,0]`, scale `.65`, the special renderer Y/Z flip,
  front GUI lighting and nearest-neighbor texture sampling. Because the live client model may
  extend beyond its render target while this project stores a bounded 64x64 PNG, the final
  projection receives a vertical-only centering correction. The v8 candidate clipped against
  the lower edge at alpha bounds `y=14..63`; the v9 result keeps the full projection at
  `y=1..61` and does not change global item coordinates. The former first-party 32x drawing
  remains only under `tools/assets/faithful32x/shield.png` as historical comparison evidence.
  Snapshot does not currently persist shield banner components, so base colors and patterns
  remain explicitly deferred rather than being guessed.
- Static chest icon: 64x transparent PNG stored under `overrides/items/minecraft/`,
  reproducibly pre-baked by `tools/ClientEquivalentChestOverrideGenerator.java` from the local
  Faithful `assets/minecraft/textures/entity/chest/normal.png`. Geometry and unfolded entity UVs
  follow the local Minecraft 26.1.2 `ChestModel`: Body x=1..15/y=0..10/z=1..15, Lid
  x=1..15/y=9..14/z=1..15 and Lock x=7..9/y=7..11/z=15..16. The baker applies the client GUI
  rotation `[30,45,0]`, fixed `0.625` scale and fixed 64x64 orthographic slot projection. It does
  not fit or recenter the visible alpha bbox and does not offset the Lock in screen space. Only
  the generated icon is bundled; the complete entity texture remains in the user's local pack.
- Priority A1 chest family: ten 64x transparent explicit overrides are generated from the local
  Faithful chest entity textures with the same Minecraft 26.1.2 `ChestModel` geometry, client GUI
  rotation `[30,45,0]`, fixed `0.625` scale and fixed slot projection as the accepted normal chest.
  The set contains trapped, ender, four copper oxidation stages and their four waxed aliases.
  Waxing does not change the entity texture, so each waxed output is intentionally byte-identical
  to its matching unwaxed oxidation stage. The Christmas trapped-chest texture is generated as a
  separate seasonal asset and is selected only from December 24 through 26; it never overwrites
  the stable normal override or its cache entry.
- Priority A2 shulker family: seventeen 64x transparent explicit overrides are reproducibly
  generated by `tools/ClientEquivalentShulkerOverrideGenerator.java` from the local Faithful
  `textures/entity/shulker/` textures. Geometry and UVs follow Minecraft 26.1.2
  `ShulkerModel.createShellMesh`: lid `(-8,-16,-8; 16x12x16)` at part offset `(0,24,0)` and base
  `(-8,-8,-8; 16x8x16)` at the same offset. The item wrapper transform and the template GUI
  `[30,45,0]` rotation with fixed `0.625` scale are applied before the fixed slot projection.
  Openness is fixed at zero because these are state-independent inventory icons.
- Bed family: sixteen 64x transparent explicit overrides are reproducibly generated by
  `tools/ClientEquivalentBedOverrideGenerator.java` from the official Minecraft 26.1.2 client
  `textures/entity/bed/<color>.png` files. The source client JAR SHA-256 is
  `B1B3158572666445EFF01E82FAD8C7DE2E4953DB6D354F311730D77A8359D0B0`, matching the accepted
  MB7 source. Geometry and UVs follow `BedRenderer.createHeadLayer/createFootLayer`; both fixed
  `BedSpecialRenderer` nodes, their local transforms, and the `template_bed` GUI transform
  `[30,160,0]`, translation `[2,3,0]`, scale `.5325` are applied before the fixed slot projection.
  Bed items have no ItemStack-dependent special-renderer argument, so no runtime color branch is
  required. Faithful 26.2 supplies no bed entity overrides; these candidates intentionally use
  the matching vanilla 26.1.2 entity textures without a second tint.
- Priority A3 Trident GUI: the 32x Faithful `textures/item/trident.png` is bundled as a runtime
  GUI-model layer, not an explicit special-renderer override. Minecraft 26.1.2
  `items/trident.json` selects the ordinary generated `item/trident` model for `gui`, `ground`,
  `fixed` and `on_shelf`; only the held fallback uses `TridentSpecialRenderer`. Inventory fixes
  the display context to GUI and therefore follows the normal 2D branch.
- Priority A4 Potion Tint Family: seven original 32x Faithful item layers are bundled under
  `runtime-composites/` for Potion, Splash Potion, Lingering Potion and Tipped Arrow. Client
  models define tintable layer0 (`potion_overlay` or `tipped_arrow_head`) followed by untinted
  layer1 (the bottle or arrow base). `PotionTintCompositor` preserves that order and alpha.
  Production tint values come from Paper `PotionMeta.computeEffectiveColor()`, which mirrors the
  Minecraft 26.1.2 rule: explicit `custom_color` first, otherwise visible effect colors weighted
  by `amplifier + 1`, with client fallback `#385DC6`. No potion-name-to-RGB table is maintained.
- First-party fallback: HuHoBot original `themes/default/items/unknown.png`.
- Ender Chest query GUI: `ender-chest-background.png` is reproducibly generated by
  `tools/EnderChestBackgroundGenerator.java` from Faithful 26.2
  `assets/minecraft/textures/gui/container/generic_54.png`. It composes the three-row upper
  container region (source rows `0..141`) with the source bottom border (`432..443`), then applies
  an exact 2x nearest-neighbor enlargement. Item textures are still resolved by the same 64x64
  Inventory pipeline; the normal player inventory and player preview are intentionally omitted.

The GUI's visible 352×332 alpha bounds are cropped and enlarged 2× with nearest-neighbor
sampling to 704×664. The survival-only 2×2 crafting controls at output pixels
`x=390..681, y=70..209` are then replaced with the adjacent Faithful panel color, producing the
blank creative-style query panel without moving armor, offhand, player, storage, or hotbar
coordinates. Native Faithful 32x 2D item textures remain 32×32 and are enlarged by an
exact nearest-neighbor factor of two at final composition. Block models and the generated
chest/shulker/bed special icons are instead rasterized directly at the final 64×64 slot size,
so they never take the former lossy 64→32→64 path. Twenty-six selected Faithful files are copied
without resampling, the generated shield/chest/shulker/bed icons are copied into `overrides/items/minecraft/`; shield's former
`assets/minecraft/shield.png` location remains only as a legacy fallback. Other selected assets use
the runtime NamespacedKey layout `assets/minecraft/<path>.png` and are not explicit overrides.
Exact source paths, SHA-256 hashes, target paths, and processing are recorded in
`ASSET_MANIFEST.tsv`.

Player Preview PV8 is rasterized directly at the active theme's final preview rectangle
(`198x283` for Faithful) instead of first producing `128x256` and applying a second non-integer
nearest-neighbor scale. Player skins retain their native Minecraft pixels; Faithful armor, trim,
overlay, and glint layers retain their existing source resolution and projection order. Modern
64x64 skin second layers are rendered for the hat, jacket, both sleeves and both trouser legs at
the client dimensions: `0.5` model-pixel expansion for the head and `0.25` for the other parts.
PV8 adds visible side walls around non-transparent outer-layer pixel boundaries and a 0.6 output
pixel bleed across shared projected faces, preserving sparse one-pixel details without black
raster cracks. Transparent UV pixels remain transparent and equipped armor renders in the later
material pass.

The independent PV8 behavior review used tr7zw's
[`3d-Skin-Layers`](https://github.com/tr7zw/3d-Skin-Layers) commit
`64326789a5caf31b6651f2edc8dd23b59f88f6f6` as a public visual/geometry reference: its head mesh
uses the standard `8x8x8`, `(32,0)` hat UV and converts present outer pixels into modeled depth.
No source, binary, or asset from that project is copied into this Addon; the Java2D edge-wall
implementation here is independent and deliberately remains a fixed-camera static PNG renderer.

`explicit-overrides.yml` is the authoritative human-readable list of final item overrides. Merely
placing a PNG in the legacy `assets/` tree does not add it to this list.

This is a bounded static 2D theme, not a complete resource-pack/model renderer. The pack
targets Minecraft 26.2; only the selected long-lived material keys are exercised against
the Paper 1.21.11 Mock fixture. This does not claim full 1.21.11 pack compatibility.
